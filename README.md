# Дневник РИСО Севастополь — Android-приложение

Готовый исходный проект Android-приложения (`ru.sev.risodiary`) с интерфейсом дневника, кэшированием расписания и авторизацией на портале `https://riso.sev.gov.ru/journal-schedule-action` через Госуслуги (ЕСИА).

## Как устроена работа в приложении
1. **app/src/main/assets/school_diary.html** — экран приложения (Расписание по дням и на всю неделю, Оценки, Почта, Новости и кнопка «Сайт»).
2. **app/src/main/java/ru/sev/risodiary/MainActivity.java** — системная оболочка Android:
   - При первом запуске проверяет наличие сессионной cookie для `https://riso.sev.gov.ru`.
   - Если вход ещё не выполнен, открывает системное окно входа РИСО → Госуслуги (ЕСИА). Как только вы входите, окно автоматически закрывается, а сессия сохраняется в памяти телефона (`CookieManager`).
   - В фоновом потоке скачивает страницу расписания выбранной недели и передаёт её в функцию `window.onRisoHtmlReceived(...)` для разбора карточек уроков и оценок.

## Как собрать установочный файл `.apk` (2 способа)

### Способ 1. Без установки программ на ПК (через GitHub Actions за 2 минуты)
1. Создайте бесплатный приватный репозиторий на GitHub и загрузите туда файлы из этого архива.
2. Перейдите во вкладку **Actions** → **Build Android APK** → нажмите **Run workflow**.
3. Через 1,5–2 минуты скачайте готовый файл `app-debug.apk` в разделе **Artifacts** и установите его на телефон.

### Способ 2. На компьютере через Android Studio
1. Откройте папку проекта в **Android Studio**.
2. В верхнем меню выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. Готовый файл появится в папке `app/build/outputs/apk/debug/app-debug.apk`.
